# Aether Storage, CDN and Gaming Model

## Storage is physical

Aether does not treat cloud storage as magical or locationless.

All persistent data ultimately exists on physical storage:

- SSD
- HDD
- flash
- distributed storage infrastructure

"Cloud" means the physical storage is operated remotely.

Aether changes the ownership and distribution model.
