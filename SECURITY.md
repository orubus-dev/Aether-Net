# Aether Security

Security is a system-wide requirement.

Aether must use established cryptographic primitives and protocols wherever appropriate.

Core requirements include:

- authenticated identities
- authenticated devices
- encrypted communication
- forward secrecy where appropriate
- secure key storage
- signed software updates
- module verification
- replay protection
- least privilege
- server-side authorization
- secure recovery
- auditability
- automatic rollback
- defense in depth

Aether must never claim that a system is literally impossible to compromise.
The engineering goal is to minimize attack surface, minimize trust, detect compromise,
and contain failures.
